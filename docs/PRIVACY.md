# Staging privacy and retention

ManakAI staging is anonymous and has no accounts. Users must not submit names, contact details, customer drawings, unpublished specifications, licence credentials or other personal/confidential material. It accepts short product/compliance questions only.

The database stores conversation text and structured product attributes for continuity, plus provider/model, latency, token counts and validation outcome. It does not intentionally store chain-of-thought, provider keys or full standards. Logs contain event names, routes, status, request IDs and bounded metrics—not prompt or response bodies.

Before a public pilot, implement an approved retention/deletion schedule, publish a privacy notice, review provider data use/region and add a deletion/security contact. Until then, use only synthetic or non-confidential inputs.
